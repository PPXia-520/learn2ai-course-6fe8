# 广告传媒课程 · 资料总览

本目录是课程的**讲义与教学资料区**，面向中国传媒大学（中传）广告学、网络与新媒体、传播学等专业方向的学生。
资料以 Markdown 编写，方便课堂投屏、打印，也方便大家用 AI 对话检索与二次整理。

## 使用说明

1. 每份讲义都是独立可读的，正文结构统一为「学习目标 → 核心概念 → 讲解 → 方法与工具 → 课堂活动 → 讨论题 → 延伸阅读」。
2. 讲义中的案例是**教学讨论用的简化叙述**，具体投放数据、榜单与舆情请以公开来源为准，课堂引用前建议核实。
3. 术语、模型与评分标准统一放在 `resources/` 与 `assessment/`，实训统一使用 `toolkit/` 里的模板。
4. 老师的资料修改会在本机保存后由应用自动同步；学生同步课程后即可看到最新版本。

## 建议的学习节奏

- **课前**：读本周讲义与指定案例，写下 2 个「我不同意 / 我看不懂」的问题。
- **课中**：参与讨论与小组演练，把老师的补充例子记在讲义对应章节旁。
- **课后**：用 `toolkit/` 模板完成当周小任务，逐步积累成期末作品集。
- **全程**：用 AI 助手做检索、对比、改稿与数据整理，但**判断与观点必须是自己的**。
