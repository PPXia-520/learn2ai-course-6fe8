# 术语表与延伸阅读

## 一、术语表

### 广告与传播基础

- **广告**：有意图地组织符号与媒介，以影响特定人群认知、态度或行为的传播活动。
- **整合营销传播（IMC）**：让品牌在所有触点上发出同一个声音、提供同一种体验。
- **触点**：受众与品牌发生接触的任何环节（广告、公关、门店、客服、包装等）。
- **传播过程模型**：强调编码—媒介—解码—反馈—噪音的传播链条。
- **5W**：Who / Says what / In which channel / To whom / With what effect。

### 受众与品牌

- **洞察（Insight）**：对受众真实心理的发现，须同时真实、意外、与品牌相关。
- **用户画像**：从人口统计、心理、行为、场景四维描述目标受众。
- **消费者决策路径**：受众从认知到购买与复购的（非线性）过程。
- **定位**：在受众心中为品牌占据一个清晰、被需要的位置。
- **品牌资产**：品牌联想的价值与其兑现的稳定性。
- **USP**：独特销售主张，强调产品层面的差异点。

### 创意与内容

- **创意简报**：把模糊需求转化为可执行任务的文档。
- **单一诉求**：一次传播只强调一个核心信息。
- **UGC / KOC / KOL**：用户生成内容 / 关键意见消费者 / 关键意见领袖。
- **分镜**：用画面、文案、音效、时长等描述视听内容的表格。

### 媒介与投放

- **媒介组合**：为达成目标而选择的多类触点的搭配。
- **覆盖与频次**：触达的去重人数与平均每人接触次数。
- **CPM / CPC / CPA**：每千次曝光成本 / 每次点击成本 / 每次行动成本。
- **有效频次**：达到记忆效果所需的最低曝光次数。
- **程序化购买**：通过技术平台自动化完成广告交易与投放。
- **RTB / DSP / SSP / ADX**：实时竞价 / 需求方平台 / 供给方平台 / 广告交易平台。
- **归因**：把转化功劳分配给各触点的规则与方法。

### 效果与合规

- **KPI / 护栏指标**：主考核指标 / 防止负面影响失控的底线指标。
- **A/B 测试**：一次只改变一个变量以判断因果的对照实验。
- **增量实验**：用对照组估计广告「额外」带来的效果。
- **广告标识**：互联网广告须显著标明「广告」以区分于其他信息。
- **绝对化用语**：如「国家级」「最高级」「最佳」等受法律限制的表述。
- **个人信息保护**：对个人信息的收集、使用与处理须合法、正当、必要并取得同意。

## 三、如何读一份行业报告

1. 先看**谁出的**：机构立场与数据来源决定可信度。
2. 再看**口径**：统计范围、时间、样本，是否与其他报告可比。
3. 找**与常识冲突的结论**：那是最值得追问的地方。
4. 记下**还不确定的**：写进你的问题清单，带到课堂。
