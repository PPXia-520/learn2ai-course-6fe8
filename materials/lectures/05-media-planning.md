# 第 5 讲 媒介策划与智能投放

## 学习目标

- 说明媒介策划的基本流程：目标 → 受众 → 媒介组合 → 排期 → 预算 → 评估。
- 解释核心媒介指标（覆盖、频次、CPM、CPC、CPA、ROI 等）的含义与适用场景。
- 为客户情境选择合适的媒介组合，并说明取舍理由。
- 理解程序化购买与智能投放如何改变媒介决策。

## 本讲导读

媒介策划要回答一个朴素的问题：**用有限的预算，在对的时间、对的地方、对的人面前，出现足够多次，并且能被衡量。** 难点在于「足够」既与钱有关，也与注意力和记忆有关。

## 一、媒介策划流程

1. **明确目标**：是提升知名度、改变认知，还是直接转化？不同目标对应不同媒介逻辑。
2. **界定受众**：规模、可触达性、媒体习惯、决策角色（谁影响、谁购买、谁使用）。
3. **选择媒介组合**：自有（官网、私域）、付费（广告位）、赚得（口碑、公关）。
4. **确定排期**：连续式、集中式（脉冲）、季节式，取决于预算和购买周期。
5. **分配预算**：按目标与效率分配，保留测试与应急空间。
6. **设定衡量**：指标、工具、归因方式、复盘节奏。

## 二、核心媒介指标速查

| 指标 | 含义 | 常见用途 |
| --- | --- | --- |
| Reach 覆盖 | 触达的去重人数 | 品牌曝光 |
| Frequency 频次 | 平均每人看到次数 | 记忆强化 |
| GRP | 覆盖 × 频次 | 传统排期总量 |
| CPM | 每千次曝光成本 | 比价、品牌投放 |
| CPC | 每次点击成本 | 引流 |
| CPA/CPS | 每次行动/成交成本 | 效果投放 |
| CTR | 点击率 | 创意吸引力 |
| ROI/ROAS | 投入产出比/广告支出回报 | 生意评估 |
| 有效频次 | 达到记忆所需的最低曝光次数 | 排期设计 |

**关键提醒**：单一指标都会误导。CTR 高不等于有效，CPM 低不等于划算，ROI 好也可能透支品牌。

## 三、媒介组合的基本逻辑

- **广度 × 深度**：用大众媒介建立认知，用垂直媒介深耕人群。
- **组合而非叠加**：不同媒介承担不同任务（认知、说服、转化、复购），避免重复覆盖同一批人。
- **内容与媒介匹配**：媒介形态决定内容规格（竖屏短视频、贴片、口播、图文）。
- **平台生态闭环**：内容场与交易场打通时，链路更短但更容易被平台规则绑定。

判断一个媒介组合是否合理，看它能否回答：**谁先看到、看到几次、看到之后做什么、怎么知道有效**。

## 四、程序化购买与智能投放

程序化的基本链条：广告主在需求方平台（DSP）设定目标与出价 → 广告交易平台（ADX）在每次曝光机会上发起竞价 → 供给方平台（SSP）/媒体返回广告 → 实时竞价（RTB）决定谁被展示。

带来的变化：

- **从买位置到买人**：按人群与目标优化，而非固定版面。
- **实时优化**：预算与出价随效果动态调整。
- **数据依赖加深**：定向与归因高度依赖平台数据，透明度和围墙花园问题突出。
- **创意自动化**：动态创意优化（DCO）按人群组合不同素材。

风险与边界：虚假流量、归因不透明、模型黑箱、隐私合规。**越是自动化，越需要人工设定合理的约束与目标。**

## 五、方法与工具

- **媒介组合与排期表模板**：见 `toolkit/working-templates.md`。
- **预算三分法**：主力投放（稳健）+ 测试预算（探索）+ 机动预算（应急/热点）。
- **「一页媒介逻辑」**：用一页纸写清目标、受众、组合、预算、指标与取舍理由，作为提案的核心页。

## 六、课堂活动：媒介组合辩论

1. 情景：某新锐国产护肤品牌，预算有限，目标是把一款新品推给一线城市 18–30 岁女性。
2. A 组主张「集中投放头部社交平台 + 直播」，B 组主张「分散铺内容 + 电商站内 + 线下快闪」。
3. 双方各用 5 分钟陈述目标、组合与理由，接受对方质询。
4. 全班用「广度—深度—闭环—可衡量」四条标准投票。

## 七、讨论题

1. 预算很少时，应该「集中一个渠道打透」还是「多点测试找方向」？
2. 归因模型各说各有理，品牌该相信谁的数据？
3. 当平台既卖广告又卖商品，媒介策划的独立性如何保证？

- 延伸阅读：媒介策划教材的「指标与排期」章节；平台官方投放产品文档；关于隐私与广告技术治理的行业报告。
