# 第 1 讲 广告与传媒生态导论

## 学习目标

- 说明广告的定义如何随媒介环境变化，区分「广告」「营销传播」「内容营销」。
- 画出并解释一张当代传媒生态地图，指出广告在其中流动的路径。
- 识别广告产业链上的关键角色及其利益关系。
- 用「数字化、平台化、算法化、智能化」四条主线解释今天的媒介环境。

## 本讲导读

先做一个练习：回想你**今天从起床到现在看到的所有广告**。地铁灯箱、朋友圈信息流、短视频口播、直播间弹窗、外卖 App 首页、播客贴片、KOL 的「真心推荐」……把它们写下来，数一数有多少。这个清单本身就是本讲的地图。

## 一、广告是什么：定义的演变

经典定义强调三个要素：**广告主付费、通过媒介、向非特定对象传递说服性信息**。但当「非特定对象」变成被算法精准匹配的个人，「付费」变成内容分成或佣金，「媒介」变成平台，这一定义的每一条都在被重写。

可以记住一个更耐用的定义：

> 广告是**在注意力稀缺的条件下，有意图地组织符号与媒介，以影响特定人群认知、态度或行为**的传播活动。

与相邻概念的区别：

- **营销传播**：范围更大，含公关、促销、直销、包装等一切与受众的沟通。
- **内容营销**：以提供有价值内容换取长期关系，往往不像「广告」那样即时索求转化。
- **公关**：目标是塑造与维护关系、议题与声誉，通常不直接购买媒介版面。

三者在实践中高度融合，所以本课程更关注「传播链条如何运转」，而不是给活动贴标签。

## 二、传媒生态地图

把生态分成四层，逐层看广告的位置：

1. **终端与场景层**：手机、电视/OTT、户外大屏、电梯屏、车载、智能音箱、可穿戴设备。决定受众在什么场景下、以什么注意力状态接触内容。
2. **内容与平台层**：社交平台、短视频/直播、长视频、资讯、电商、搜索、播客、游戏、线下媒体。决定内容的形态、分发规则与可购买的广告位。
3. **分发与算法层**：推荐系统、搜索排序、竞价广告系统。决定「谁能看到什么」，是当代广告最关键也最不透明的一层。
4. **基础设施层**：数据与标签体系、广告交易平台（DSP/SSP/ADX）、监测与归因工具、结算与合规系统。

理解这四层，就能回答一个实用问题：**一条广告为什么没被看到，或被看到却没转化？** 可能是内容不吸引（层 2）、投放定向错了（层 3）、场景不匹配（层 1），或数据与归因失真（层 4）。

## 三、广告产业链与角色

| 角色 | 主要职能 | 关心的核心指标 |
| --- | --- | --- |
| 广告主（品牌方） | 定目标、给预算、承担品牌责任 | 生意增长、品牌资产、ROI |
| 代理商（创意/媒介/整合） | 提供策略、创意与媒介服务 | 客户满意度、作品获奖、续约 |
| 媒介与平台 | 提供内容场与广告位、制定规则 | 广告收入、用户规模与时长 |
| 技术公司/MarTech | 提供投放、数据、监测工具 | 产品收入、模型效果 |
| 内容创作者/KOL/MCN | 生产内容与信任背书 | 粉丝增长、内容效果、商单 |
| 受众/消费者 | 注意、互动、购买、评价 | 体验、价值、被尊重感 |

值得记住的张力：广告主要效果，平台要时长，创作者要粉丝，受众要体验。**优秀的广告是这几方利益的交集**，而不是任意一方的单赢。

## 四、中国广告市场的若干结构特征

以下为结构性观察，具体份额与规模请以最新公开报告核实：

- **平台高度集中**：头部互联网平台同时是内容场、广告位与数据源，掌握分发权力。
- **移动与短视频主导**：用户时长向短视频、直播与社交迁移，预算随之迁移。
- **效果广告比重高**：可归因、可结算的投放形式占比大，品牌广告与效果广告的平衡长期争论。
- **电商与内容打通**：种草—搜索—下单链路在同生态内闭环，广告与交易的边界变模糊。
- **合规与算法监管加强**：广告标识、个人信息保护、算法推荐管理等规则持续细化。
- **出海与本地化并行**：越来越多品牌与代理商把中国打法迁移到海外市场。

> 课堂任务：任选一条特征，从近一年的公开新闻或报告中找一个支持或反驳它的证据。

## 五、媒介环境变化的四条主线

1. **数字化**：一切内容与交易转为数据，可存储、可计算、可复用。
2. **平台化**：分发权从媒体机构转移到平台，平台规则成为事实上的行业标准。
3. **算法化**：从「买版面」到「买人群与目标」，创意与出价共同决定曝光。
4. **智能化**：生成式 AI 参与洞察、创意、生产、投放与优化，人机协作成为常态。

四条主线叠加的结果：**广告从「买媒介」变成「买一个持续优化的传播系统」**。

## 六、可用得上的经典模型

- **5W（拉斯韦尔）**：谁（Who）—说什么（Says what）—通过什么渠道（In which channel）—对谁说（To whom）—取得什么效果（With what effect）。用于快速梳理一次传播的骨架。
- **AIDA**：注意（Attention）—兴趣（Interest）—欲望（Desire）—行动（Action）。用于理解消费者从看到到购买的心理阶段。
- **传播过程模型**：强调「编码—媒介—解码—反馈—噪音」。提醒我们受众的解码可能完全不同于发送者的编码意图。

模型的意义不在于背诵，而在于**暴露你漏掉的环节**。

## 八、课堂活动：生态地图与角色辩论

1. 每人独立画出「我一天接触的媒介与广告」地图（5 分钟）。
2. 小组合并地图，标出「广告主最想要但最难买到」的位置（10 分钟）。
3. 分组扮演广告主、平台、创作者、受众，就「一条信息流广告该不该默认播放声音」进行 4 方辩论（20 分钟）。
