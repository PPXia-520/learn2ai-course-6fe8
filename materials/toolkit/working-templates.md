# 实训模板合集

以下模板可直接复制使用。建议每完成一次实训就留存一份，逐步形成个人作品集。

## 模板 1 媒介生态地图

```
【我一天接触的媒介与广告】
时间段 | 场景 | 媒介/平台 | 内容形态 | 我的注意力（高/中/低） | 我有没有行动
...

【观察结论】
- 广告最集中的时段/场景：
- 我注意力最高但广告最少的位置（机会点）：
- 让我产生行动的内容有什么共同点：
```

```

三、行为：媒体使用 / 搜索词 / 购买频次 / 决策周期 / 复购与流失
四、场景：时间 / 地点 / 情绪状态 / 触发事件

【原始素材与来源】
- 访谈对象（匿名化）：
- 平台评论/热帖：
- 数据来源：

【洞察结论】
- 我观察到（证据）：
- 我判断（受众）在（场景）中真正想要的是（深层需求）：
- 因此（品牌）可以（行动）：

【局限与不确定】
- 样本局限：
- 可能的偏见：
```

## 模板 8 效果复盘

```
【本次投放复盘】
1. 目标与实际：主指标达成情况
2. 发生了什么：关键数据与异常
3. 我判断为什么：可能的原因（区分相关与因果）
4. 不确定的地方：数据质量/混淆变量
5. 下一步行动：具体、可执行、有负责人与时间
```

## 模板 9 合规自检清单

```
□ 广告主资质与特殊行业审批是否齐备
□ 所有宣称是否有可核实的依据
□ 是否使用绝对化用语或不当比较
□ 互联网广告是否显著标明「广告」
□ 付费种草/软文是否披露商业关系
□ 数据收集与定向是否合法、正当、必要并取得同意
□ 是否涉及未成年人、老年人等特殊群体保护
□ 落地页与广告内容是否一致
□ 证据（数据来源、审批、投放记录）是否留存
```
